# 01 - Getting Started

This guide takes a new team member from a clean machine to playing the game in the Unity editor. It covers the exact tool versions, cloning, first import, Unity licensing, and the one-time git setup for merging Unity scene files. Read it top to bottom on your first day.

## 1. Required software

| Tool | Version | Why |
|---|---|---|
| Unity Hub | 3.x (tested 3.22.3) | Signs you in, manages the editor licence, installs editors |
| Unity Editor | **6000.4.11f1** exactly | The project is pinned in [ProjectSettings/ProjectVersion.txt](../ProjectSettings/ProjectVersion.txt). Other versions will trigger an upgrade; do not accept one without agreeing it as a team. |
| Git | 2.40+ | Source control |
| Blender | 5.2 | Only needed if you edit art in `ArtSource/` (see [05-art-pipeline.md](05-art-pipeline.md)) |
| Python | 3.11+ | Only for the `ArtSource/Audio/tools` helpers |

The project was built on macOS (Apple Silicon). Nothing in the runtime code is macOS-specific, but some Blender helper scripts contain machine-specific paths; [08-handover-notes.md](08-handover-notes.md) lists them.

### Installing the editor

1. Install Unity Hub (macOS: `brew install --cask unity-hub`, or download from unity.com).
2. Open Hub and **sign in** with your Unity account (profile icon, top left).
3. Hub: **Preferences > Licenses > Add** and activate a licence (Unity Personal or your organisation's seat).
4. Hub: **Installs > Install Editor > Archive** and install `6000.4.11f1`. No extra platform modules are required to run in the editor; add Windows/macOS Build Support only if you need player builds.

> If the editor opens and immediately reports **"No valid Unity Editor license found"**, you are not signed in to Hub, or Hub is not installed. The editor gets its licence through Hub's licensing client. Sign in to Hub, add a licence, then reopen the project.

## 2. Clone and open

```bash
git clone https://github.com/calebsnyder-DRT/Real-Golf.git
```

Then in Unity Hub: **Projects > Add > Add project from disk** and select the cloned `Real-Golf` folder. Hub will pick editor `6000.4.11f1` automatically.

The **first open takes several minutes**. Unity rebuilds the `Library/` cache (not in git) and imports about 1 GB of assets. Later opens take well under a minute.

When the import finishes, the Console should show **no compile errors**. If it does, check that you opened the project with exactly 6000.4.11f1.

## 3. Play the game

1. Open the scene **`Assets/_Game/Scenes/Main.unity`**. It is the only scene in Build Settings, and the game boots from it.
2. Press **Play**.
3. Follow the on-screen flow: player setup, then the Pro Shop, then the course. Controls are listed in [03-gameplay.md](03-gameplay.md#controls).

`Assets/_Game/Scenes/ProShop.unity` is a preview and authoring scene for the Pro Shop and golfer art. It is not the game's entry point.

## 4. One-time git setup for Unity files

Scenes, prefabs and assets are YAML text. [.gitattributes](../.gitattributes) routes them to Unity's YAML merge tool. Each developer must tell git where that tool lives, once:

```bash
git config --global merge.unityyamlmerge.name "Unity SmartMerge"
git config --global merge.unityyamlmerge.driver "'/Applications/Unity/Hub/Editor/6000.4.11f1/Unity.app/Contents/Helpers/UnityYAMLMerge' merge -p %O %B %A %A"
git config --global merge.unityyamlmerge.recursive binary
```

On Windows the tool is at `C:\Program Files\Unity\Hub\Editor\6000.4.11f1\Editor\Data\Tools\UnityYAMLMerge.exe`. If you skip this step, git falls back to its normal text merge, which works for small changes but can corrupt scene files on conflicting edits.

Team rules that keep merges sane:

- Only one person edits `Main.unity` at a time. Most scene content is **generated by editor menu commands** (see [04-editor-tools.md](04-editor-tools.md)), so prefer re-running the bake over hand-editing the scene.
- Always commit the `.meta` file together with its asset. A missing `.meta` breaks every reference to that asset.
- Never commit `Library/`, `Temp/`, `Logs/`, `UserSettings/` or `Build/`. [.gitignore](../.gitignore) already excludes them.

## 5. Repository layout

```
Real-Golf/
├── Assets/
│   ├── _Game/                 All project code and content
│   │   ├── Scripts/
│   │   │   ├── Core/          Engine-agnostic game logic (Puttshack.Core.asmdef)
│   │   │   ├── Hardware/      Device/emulator layer (Puttshack.Hardware.asmdef)
│   │   │   ├── Runtime/       MonoBehaviours, views, course, HUD, shop (Puttshack.Runtime.asmdef)
│   │   │   └── Editor/        Bake/verify/capture tools under the "Puttshack" menu (Puttshack.Editor.asmdef)
│   │   ├── Tests/             EditMode + PlayMode test assemblies
│   │   ├── Scenes/            Main.unity (game), ProShop.unity (preview/authoring)
│   │   ├── Course/Baked/      Generated course meshes, materials and prefabs (output of "Bake Course")
│   │   ├── Art/               Characters, clubs, materials imported from ArtSource exports
│   │   ├── Resources/         Assets loaded by path at runtime (models, libraries)
│   │   ├── Prefabs/, Shaders/
│   ├── Settings/              URP pipeline + renderer assets
│   └── TextMesh Pro/          TMP essentials
├── ArtSource/                 Blender sources, export files, Mixamo FBX, UI/audio sources (not imported by Unity)
├── Packages/manifest.json     Unity package versions
├── ProjectSettings/           Unity project settings (committed)
└── docs/                      This documentation
```
